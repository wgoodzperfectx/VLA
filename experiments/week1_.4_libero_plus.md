#  LIBERO-Plus 的鲁棒性评价维度

## 背景概述

LIBERO-Plus是LIBERO基准的扩展版本，专门用于评估VLA模型在面对环境扰动时的鲁棒性。相比原始LIBERO，Plus版引入了7种不同类型的干扰因素，覆盖感知层、语义层和物理层。本文档逐项记录各维度的定义、实验效果及初步分析。

## abstract可知

1. 虽然VLA 模型很火，论文中的常规测评成功率很高，但是实际上很脆弱

2. 那些会导致模型翻车？
   + 摄像头角度或机械臂的起始位置，模型就很容易失败。
   + 物体布局、光照条件、背景纹理、传感器噪声。

3. 对人的指令听不懂，倾向于 “看”

4. 结论
   + 高分的测试并不等于实际的使用评价。
   + 在测试过程中要做到建立新的评测标准，重点考察模型在**真实、多变环境下**的可靠性。

## 七个维度

### objects layout  对象布局

改变场景中物体的初始位置、朝向或相对顺序（如将杯子放在盘子左侧改为右侧），模型过度依赖训练数据中的空间先验，缺乏对布局变化的泛化能力

### camera viewpoints 摄像机视角

改变相机相对于工作台的高度、角度或距离，视角变化导致视觉特征分布偏移，模型难以正确识别物体和相对位置

### robot initial states 机器人初始状态

改变机械臂的起始关节角度或末端执行器初始位置，对运动规划模块的依赖大于视觉模块，但VLA端到端模型仍受影响

### language instructions 语音指令 

使用同义替换、语序调整、省略修饰词等方式改写指令，模型对指令的语义理解不够鲁棒，倾向于记忆固定句式而非理解意图

### light conditions 光照条件

改变场景整体亮度、光源方向或引入局部阴影，语言指令提供的先验信息在一定程度上补偿了视觉退化

### background textures 背景纹理

更换工作台表面的纹理图案（如木纹换大理石纹）或在背景中添加干扰物体，模型的视觉编码器对背景纹理有一定鲁棒性，但对显著性干扰敏感

### sensor noise 传感器噪声

在图像或深度图中加入高斯噪声、椒盐噪声或随机遮挡像素块，噪声容忍度取决于模型使用的视觉骨干网络，ViT比CNN略好

## 结论（主要存在的问题）

1. __泛化__ 
   + 降低视觉上的依赖：灵活处理不同摄像头方向，光照条件，背景纹理，物体布局
   + 降低机器人自身设定的依赖，对不同力学动作和复杂的活动都有响应并处理
   
2. 综合上述7个维度的实验结果，**VLA模型在以下两类扰动下表现最为脆弱**：

   1. **相机视角变化**（影响程度最高）

      原因：VLA的视觉编码器通常假设固定的观察角度，视角偏移直接改变了输入分布，而训练数据中视角多样性不足。

      后果：成功率降幅最大，且难以通过简单数据增强弥补。

   2. **语言指令的同义替换与信息缺失**

      原因：VLA的语言编码器对句法结构的敏感性高于语义理解，模型容易过拟合训练集中的指令模式。

      后果：指令稍作改动即导致失败，说明模型并未真正“理解”任务，而是记住了模式。

     **次脆弱维度**：物体布局变化（空间泛化能力弱）、传感器重度噪声（感知退化）。

3. **对设计防御策略的启发**

| 多视角训练   | 相机视角   | 在训练阶段引入随机视角采样，或使用视角不变的特征提取器     |
| ------------ | ---------- | ---------------------------------------------------------- |
| 指令语义增强 | 语言指令   | 引入指令改写数据增强，训练模型对同义句的等价推理能力       |
| 布局正则化   | 物体布局   | 增加布局随机化比例，或在隐空间中约束布局无关特征           |
| 噪声鲁棒编码 | 传感器噪声 | 使用去噪自编码器或对抗训练提高视觉骨干的噪声容限           |
| 跨模态校验   | 多维度综合 | 利用视觉和语言的双向一致性检验（如视觉确认物体后再执行动作 |
